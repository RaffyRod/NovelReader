15 mocks de UI para el hueco «instalado» vs «en Buscar». Elige una letra; el mock respeta Ultimate Blue / tema actual.

¿LNReader pone el plugin en Buscar al instalar? Sí, en LN el plugin es un motor JS: al instalarlo ya puede buscar novelas. En Ultimate el JS se guarda, pero la pestaña Buscar usa proveedores CSS (Madara / Blogger / selectores). Por eso existe «Añadir a Buscar»: mapear el sitio a un proveedor que Ultimate sí entiende. Ideal de producto: al instalar, activar Buscar automáticamente cuando haya plantilla fiable (Madara/Blog detectado); si no, dejar un paso corto — no un callejón sin salida «solo JS».
